# Fake News Detector Using Machine Learning

## Project Overview
This project uses machine learning to classify news articles as REAL or FAKE using text analysis and TF-IDF vectorization.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorization

## Machine Learning Models
1. Logistic Regression
2. Naive Bayes
3. Random Forest
4. Support Vector Machine (SVM)

## Dataset
The project uses a dataset of news articles for training and testing the models.

## Objective
To explore how machine learning can help identify potentially fake news articles.
